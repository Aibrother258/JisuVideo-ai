# HB-20260831-03：可调整工作台布局

## 1. 迭代概况

- 日期：2026-08-31
- 状态：工程化收口已完成；前端生产构建与新增布局回归测试通过，完整旧测试集仍有历史路径/断言失败
- 目标：让视频生成工作台和分镜拆分工作台支持面板宽度/高度拖拽调整，并在刷新后保留用户布局。
- 影响模块：`frontend/app/views/drama/episode.vue`、工作台响应式布局、浏览器本地布局偏好。

## 2. 原始问题

原工作台采用固定三栏/上下布局。视频任务列表、视频预览与提示词，以及分镜列表、描述、提示词、参考素材之间无法按内容长度和屏幕尺寸调整。长提示词、长分镜描述和任务列表同时出现时，用户需要频繁滚动或切换区域。

## 3. 本次范围

### 做了

- 左侧导航宽度、高度可调整。
- 视频任务列表宽度可调整。
- 视频预览区与提示词区高度可调整。
- 视频工作台整体高度可调整。
- 分镜列表、描述区、参考素材区宽度可调整。
- 中文视频提示词与 H3 提示词区域高度可调整。
- 分镜工作台整体高度可调整。
- 拖拽、键盘方向键、`Shift + 方向键`、`Home` 恢复、双击恢复默认。
- 布局偏好写入 `localStorage`，刷新后恢复。
- 保留窄屏单栏降级，不在窄屏强行显示三栏。

### 不做

- 不引入第三方拖拽/布局库。
- 不改变视频生成、分镜、提示词和素材库业务逻辑。
- 不把布局偏好写入数据库。
- 不在本次迭代重构整个 `episode.vue`。

## 4. 关键设计

- 使用 Pointer Events，兼容鼠标和触控输入。
- 使用 CSS 自定义属性驱动 Grid 宽度和高度。
- 每个分隔线拥有明确的最小/最大尺寸。
- 分隔线使用 `role=separator` 和键盘操作。
- 默认值用 `0` 表示使用响应式 CSS 默认值。
- 当前布局偏好按浏览器用户共享，不按剧集保存。
- 窄屏断点继续自动关闭内部拖拽，改用纵向布局。

主要实现集中在：

## 8. 已知限制

- 布局偏好目前是全局浏览器偏好，不支持跨设备同步。
- 窄屏模式会隐藏内部拖拽分隔线，这是有意的响应式降级。
- `episode.vue` 仍然较大，布局逻辑后续应抽到独立 composable。

## 9. 回滚方式

删除本次新增的布局状态、分隔线事件和布局 CSS，恢复工作台原有 Grid 默认值即可。业务数据、素材和任务数据不受影响。

## 10. 后续建议

1. 抽出 `usePanelLayout.ts`，集中管理布局状态和拖拽。
2. 抽出通用 `PanelResizer.vue`，统一无障碍属性与交互。
3. 如果后续需要多人协作，再设计数据库中的用户/工作台布局偏好表。
