## 记录规范

每篇日志至少包含：

1. 需求与原始问题。
2. 本次范围和明确不做的内容。
3. 关键设计决策与原因。
4. 前端、后端、数据库、Agent/Skill 等分层改动。
5. 用户实际操作路径。
6. 验证证据和未通过项。
7. 已知限制、风险与回滚方式。
8. 后续迭代建议。

除非日志明确写明“真实生成已验证”，否则模型调用和付费生成能力只视为结构接通。
