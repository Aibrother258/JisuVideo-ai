## 关键设计决策

| 决策 | 背后逻辑 |
|---|---|
| **三栏「目录—详情」取代长页锚点** | 设置页二级项多且每项内容独立，长页滚动 + 锚点定位心智重；点目录即切换内容区，目录高亮与内容一一对应，天然适配后续新增管理区 |
| **中栏数据驱动、增删只改一处** | `navGroups` 双层目录 + 二级项（含风格、Agent、Skill 计数徽标）来自数据而非模板写死 |
| **风格编辑就地化 + 草稿保护** | 详情卡直接编辑（同页保存），而非弹窗；一切「离开当前编辑目标」的动作（切风格/添加/刷新/关页）统一过草稿确认，杜绝静默丢失 |
| **变基到最新 master 再提交** | 按 owner 合并顺序指示：先合并 #15，再把本分支变基到新 master，避免设置页改动与 token 收敛（PR #15）冲突 |
