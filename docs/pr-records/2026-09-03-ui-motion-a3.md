## 关键设计决策

| 决策 | 背后逻辑 |
|---|---|
| **六档时长 token，值=现状众数** | 0.12/0.16/0.18/0.22/0.32 各为现状主要档位值，改 token 后引用处视觉零变化；slow 取 0.30/0.32/0.35 中值 0.32（而非众数 0.35），使 settings-scroll/episode 空态（0.30s，真实运行）偏差仅 0.02s 且在 0.03s 验收边界内 |
| **显式补 `--ease-out` 而非保留默认** | 浏览器 transition 默认缓动为 ease（对称、快进快出），与现用出加速 `--ease-out` 观感不一致；补全后「无缓动残留」可被测试守卫 |
| **线性/缓入仅限旋转与骨架循环** | spin 用 linear（匀速旋转无惯性感）、skeleton 用 ease-in-out（脉动对称）属语义必要，列入例外清单而非归一 |
| **keyframes 收敛至 studio.css 单一来源** | detail/index 局部 spin 与全局定义完全同值；scoped 样式删除局部定义后引全局不受影响，消除双份维护 |
| **动画连续值（进度条/骨架）不入时长档** | 时长档为「一次性离散过渡」设计；进度条 0.28s、骨架循环等连续/循环值强改会破坏语义，列为例外并记录 |
