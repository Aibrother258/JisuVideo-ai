## PR 描述（可直接粘贴）

### 背景

对项目全链路（生成 → 轮询 → 下载 → 回写 → 合并 → 上传）的深度排查确认：功能链路完整，但存在多个「运行中才会暴露」的稳定性风险——服务重启即丢任务、大文件整体进内存下载、无并发控制、请求无重试、上传无格式校验。本 PR 实施第一批（稳定优先），不新增功能按钮。

### 1. 任务启动恢复（P0，防重启丢任务）

此前 `index.ts` 启动时把残留的 `processing` 任务**统一标记 failed**，已提交厂商的生成任务（可能已产生费用）直接作废。

现在改为 `services/recovery.ts` 差异化处理：

| 状态 | 处理 |
|---|---|
| `sys_task` 视频任务（有上游 `taskId`） | **认领续轮询**：上游任务可能仍在生成，恢复查询 → 完成则下载落盘，不重复提交、不重复扣费 |
| `sys_task` 视频任务（无 `taskId`，创建阶段中断） | 重新走完整提交流程 |
| `sys_task` 图片任务 | 标记 failed（轮询窗口仅 10 分钟，重启后大概率已过期，恢复价值低） |
| `video_merges` 残留 processing | 标记 failed（本地 ffmpeg 操作无上游任务可续） |

配置匹配：优先按「同 provider + 模型列表包含原任务 model」精确命中原配置（保住集锁定语义），找不到再回退当前启用配置。

### 2. 下载加固（P0，防内存 OOM / 无限等待）

`downloadFile` 由「`arrayBuffer()` 整体进内存再写盘」改为**流式写盘**：

- 边下边写，视频（可达数百 MB）不再整文件驻留内存；
- `Content-Length` 预检 + 实时字节计数双保险，超限立即中止并删除半成品；
- 单次尝试默认 10 分钟超时（`AbortSignal.timeout`）；
- 网络错误 / 5xx / 超时自动重试（`withRetry`），4xx 不重试。

调用侧上限：图片 50MB、视频 2GB。

### 3. 统一重试封装（P0）

新增 `utils/retry.ts`：`withRetry` + `isRetryableError`（AbortError / TypeError / 429 / 5xx 可重试，4xx 业务错误不重试），指数退避。

接入点：

| 调用点 | 重试次数 | 说明 |
|---|---|---|
| 创建生成请求 | 2（共 3 次尝试） | 网络抖动 / 上游 5xx / 限流 |
| 轮询请求 | 1（每轮内重试 1 次） | 仍失败交给外层轮询循环等下一轮 |
| 文件下载 | 2 | 重试重新下载，新文件名 |

### 4. 批量并发控制（P0，防打爆厂商 API）

新增 `utils/concurrency.ts` 信号量。`processTask` 在整个任务生命周期（提交 + 轮询 + 下载）持有槽位，`finally` 释放：

- 视频同时运行 **2** 个，图片同时运行 **4** 个（环境变量 `VIDEO_CONCURRENCY` / `IMAGE_CONCURRENCY` 可覆盖）；
- 超限任务**排队等待**而非报错，前一个完成后自动接续；
- 启动恢复的任务同样受信号量约束，不会重启瞬间打满上游。

### 5. 图片上传校验（P1）

`/upload/image` 增加格式白名单（png/jpg/jpeg/webp/gif，扩展名 + MIME 双校验）与 10MB 上限；先用 `file.size` 预检（不读进内存）再 `arrayBuffer`。

### 详细日志

全部关键路径接入现有 `task-logger`，格式 `[scope] action | k=v`：

- `[Recovery] START/DONE interrupted-tasks | resumed=.. failed=.. elapsedMs=..`
- `[Concurrency] VideoSlot-acquire/queue-wait/release | id=.. active=.. waiting=.. limit=..`
- `[VideoTask]/[ImageTask] create-request-retry | attempt=.. maxAttempts=.. retryInMs=.. error=..`
- `[VideoTask]/[ImageTask] poll-request-retry | attempt=..`
- `[Storage] download-start/done | subDir=.. url=..(脱敏) bytes=..`、`download-retry`
- `[VideoTask] resume | id=.. hasTaskId=.. provider=..`、`[SysTask] resume-config-matched`
